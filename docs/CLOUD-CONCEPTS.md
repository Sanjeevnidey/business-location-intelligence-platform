# Cloud concepts demonstrated

1. Cloud-hosted database: MongoDB Atlas.
2. API-based data ingestion: Overpass/OpenStreetMap.
3. Cloud-accessible application architecture.
4. Security: environment variables and backend-only secrets.
5. Scalability: stateless API design, filtering and pagination strategy.
6. Monitoring: health endpoint and deployment-platform logs.
7. Cost optimization: public/open data and free-tier resources where available.
